# 🏀 Chef Curry — A Basketball Shooter

A single-file HTML basketball game inspired by Steph Curry's three-point
shooting. Click to set the **POWER** (vertical meter) and **ANGLE**
(horizontal meter), and watch the ball arc toward the rim.

## 🎮 How to Play

1. Click **PLAY** on the title screen
2. Click anywhere to set **POWER** when the indicator is in the green zone
3. Click anywhere to set **ANGLE** when the indicator is in the green zone
4. Watch the ball trajectory — if you hit the green zones, the ball
   arcs cleanly through the rim

## 🏆 Scoring

- **PERFECT 3!** (3 points) — click in BOTH green zones
- **SCORE!** (1 point) — make the basket from outside the green zones
- **MISS** — no points, but the ball still follows its real trajectory

## 📁 Local Play

Just open `index.html` in any modern browser. No build step, no
server, no dependencies. Works offline once loaded.

## 🛠️ Tech

- Single-file HTML5 Canvas game
- No external libraries
- Pure vanilla JavaScript, CSS, and HTML
- Runs at 60fps with time-based physics
